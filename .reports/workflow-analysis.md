## 🔄 工作流程分析

### 1. 启动流程

```
┌─────────────────────────────────────────────────────────────┐
│                     启动流程                                  │
├─────────────────────────────────────────────────────────────┤
│  1. 加载配置 (config.json)                                   │
│     ↓                                                        │
│  2. 初始化日志系统                                           │
│     ↓                                                        │
│  3. 初始化证书管理器 (自动生成CA证书)                        │
│     ↓                                                        │
│  4. 创建代理服务器                                           │
│     ├── 流量处理器 (Processor)                              │
│     ├── 流量模式识别 (PatternHandler)                       │
│     ├── 指纹识别引擎 (FingerprintHandler)                   │
│     └── 访问控制器 (AccessController)                       │
│     ↓                                                        │
│  5. 加载插件 (.so 动态库)                                    │
│     ↓                                                        │
│  6. 启动监听服务                                             │
│     ├── 代理端口: 8081                                      │
│     └── 监控端口: 9090                                      │
└─────────────────────────────────────────────────────────────┘
```

### 3. 插件系统流程

```
┌─────────────────────────────────────────────────────────────┐
│                    插件生命周期                              │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  1. 加载插件 (.so 文件)                                      │
│     ↓                                                        │
│  2. 调用 NewPlugin() 创建实例                                │
│     ↓                                                        │
│  3. 调用 Initialize(config) 初始化                          │
│     ↓                                                        │
│  4. 注册钩子函数                                             │
│     ├── HookBeforeRequest  (请求前)                         │
│     ├── HookAfterRequest   (请求后)                         │
│     ├── HookBeforeResponse (响应前)                         │
│     ├── HookAfterResponse  (响应后)                         │
│     ├── HookOnError        (错误时)                         │
│     └── HookOnFilter       (过滤时)                         │
│     ↓                                                        │
│  5. Start() 启动插件                                        │
│     ↓                                                        │
│  6. 运行中：执行钩子函数                                     │
│     ↓                                                        │
│  7. Stop() 停止插件                                         │
│     ↓                                                        │
│  8. Cleanup() 清理资源                                      │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

## 📋 使用建议

### 推荐配置

#### 1. 快速测试模式
```bash
./build/hackmitm -config configs/config-no-plugins.json
```
- 禁用插件，启动快速
- 适合基础代理需求

#### 2. 完整功能模式
```bash
make plugins  # 先构建插件
./build/hackmitm -config configs/config.json
```
- 启用所有插件
- 适合安全研究

#### 3. 调试模式
```bash
./build/hackmitm -config configs/config.json -log-level debug
```
- 详细日志输出
- 适合问题排查
